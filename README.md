# KaQ8_test_task
Сервис управления платёжными аккаунтами. Эмулирует обработку вебхуков от сторонней платёжной системы. Техническое задание на позицию "Python Backend Developer". Текст задания доступен [прямо в репозитории](https://github.com/SLotAbr/KaQ8_test_task/blob/main/Backend%20Python%20Task.pdf).

## Детали

Безопасность:
* JWT аутентификация (OAuth2 Password Flow)
* Управление доступом на основе RBAC
* Взаимодействие с базой данных пользователей доступно только администраторам
* Цифровая подпись для транзакций на основе секретного ключа и SHA256 хеша
* Защита от SQL инъекций
* Тестовый аккаунт администратора, учётные данные лежат в `.env.example`

Компоненты:
* Обработчик транзакций (вебхуки от сторонней платёжной системы)
* Миграции на Alembic
* Docker контейнеры для PostgreSQL базы данных и сервиса приложения
* Ядро на FastAPI, Pytest тесты, все взаимодействия асинхронны

## Инструкции по установке и запуску
1. Сервис целиком обёрнут в Docker контейнеры. Для первого запуска: `make apply-first-migrations-and-run`
1. Помимо ручного тестирования, доступно автоматическое: `make test`

Пароли и почта для ручного тестирования лежат в `.env.example`.<br>
Swagger UI документация с описанием всех методов приложения доступна локально: `http://localhost:8000/docs`
